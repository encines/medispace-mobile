# Contribuir a Medispace Mobile

Gracias por tu interés en contribuir. Pasos rápidos:

- Abre una issue para proponer cambios grandes.
- Haz un fork y crea una rama con un nombre descriptivo.
- Sigue la convención de commits (feat/fix/docs).
- Incluye screenshots si tocas UI (`assets/screenshots/`).
- Ejecuta `npm install` y `npm start` para probar localmente.

Mantén PRs pequeños y enfocados.
